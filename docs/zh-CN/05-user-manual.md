# Smart Site· 用户手册

> 适用对象：使用本平台进行组态画面编辑、设备接入与数据可视化运营的人员（工程师、运维、管理人员）。
> 本文聚焦"怎么用"。安装部署见 [部署运维](./部署运维.md)，源码开发与扩展见 [开发指引](./README.md)。

---

## 1. 平台概述

Smart Site 是一套工业组态与数据可视化平台，提供两条主要使用入口：

| 入口 | 路径 | 定位 |
| --- | --- | --- |
| 组态编辑器 | `/editor` | 拖拽式监控画面编辑、图元绑定、数据联动 |
| 数据中台 | `/system` | 设备管理、数据标签、数据源、报警、报表、脚本 |

核心能力覆盖：拖拽式组态编辑、图元与数据绑定、工业协议采集（Modbus / OPC UA / MQTT / S7 / virtual）、数据标签与模板、报警引擎、脚本引擎、多语言国际化（中 / 英）。

---

## 2. 登录与账号

- **自部署访问**：浏览器打开 `http://<主机>:<前端端口>/system` 或 `/editor`（端口见 [部署运维](./部署运维.md)）。
- **演示站点**：<https://smartsite.top/>，测试账号 `test` ／ 密码 `test`（公开共享实例，请勿写入重要业务数据）。
- **首次启动**：数据库未初始化时，打开前端会引导进入**初始化向导**，先创建 `admin` 账号即可登录。
- **角色权限（RBAC）**：`admin` / `user` / `viewer`，按最小权限分配。
- **语言切换**：界面支持中文 / 英文切换（基于 vue-i18n）。

## 3. 组态编辑器（`/editor`）

### 3.1 项目管理

- 新建 / 打开 / 删除项目；一个项目可包含多个**页面**。
- 支持项目**导入 / 导出**（项目包，便于迁移与备份）。

### 3.2 画面编辑

- 画布基于 Konva 渲染，支持缩放、网格、对齐辅助线、图层管理、撤销 / 重做。
- 从**图元库**拖拽图元到画布；图元可调整位置、大小、旋转、层级。
- 图元库按插件分组，常见有：
  - `basic`：基础图形、文本、按钮、输入框等
  - `chart`：基于 ECharts 的图表（折线、柱状、饼图等）
  - `industrial`：工业控件（仪表、阀门、管道等）
  - `electric`：电气符号

### 3.3 图元绑定与数据联动

- 选中图元 → 在**属性面板**中绑定**数据标签（datatag）**或设备测点。
- 支持将实时值显示为文本 / 颜色 / 显隐：可配置阈值、表达式实现联动。
- 事件交互：点击跳页、弹窗、触发脚本等。

### 3.4 预览与发布

- 通过 `/preview` 预览运行效果。
- 保存后发布为运行画面，供数据中台或前端访问。

---

## 4. 数据中台（`/system`）

### 4.1 设备管理

- 设备的增删改查、分组管理。
- 实时**连接状态**监测：在线 / 离线 / 异常。
- 采集协议配置：Modbus（TCP/RTU）、OPC UA、MQTT、S7、virtual（模拟）等。

### 4.2 数据标签（datatag）

- 绑定设备测点，定义名称、单位、数据类型、采集周期。
- 数据标签是图元绑定的**数据来源**，是连接"采集—展示"的关键对象。

### 4.3 数据源（datasource）

- 接入外部数据源（数据库 / API），扩展数据来源。

### 4.4 报警管理

- 配置报警**规则**（阈值 / 条件）、报警级别。
- 报警**确认 / 清除**；触发后通过 WebSocket **实时推送**到前端。

### 4.5 报表（report）

- 定时或手动生成报表，数据来源于数据标签 / 历史数据。

### 4.6 脚本引擎（script）

- 编写自定义计算 / 联动脚本，扩展业务逻辑。

---

## 5. 实时数据

- 前端通过 WebSocket（Socket.IO）接收实时推送，**无需刷新**即可看到实时值、报警与设备状态变更。
- 订阅粒度以**项目**为单位（房间隔离），保证数据隔离与安全。

---

## 6. 使用建议与提示

- 演示站点 / 演示数据为**模拟产生**，不涉及真实工艺与业务数据，请勿写入重要信息。
- 各项目数据**按项目隔离存储**，便于多项目并行管理。
- 建议先通过"导入示例项目"熟悉编辑器与数据联动流程。

---

## 7. 常见问题

- 无法登录 / 接口 401：确认账号密码、JWT 是否过期，开发环境可参考前端 `VITE_DEBUG_SKIP_AUTH`。
- 实时数据不刷新：检查 WebSocket 连接（网络 / 代理是否放行 `/socket.io`）。
- 设备离线：检查网络与协议参数配置，详见 [部署运维 · 常见问题](./部署运维.md#常见问题) 与 [04-常见问题排查](./04-troubleshooting.md)。
